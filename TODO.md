## Unexplained errors (dev only so far)

- [x] **Full dev-server suites slowing to 7–9 min and timing out: found and fixed (2026-09-26).** It wasn't the dev server itself, which rarely used more than one core. The whole machine was overloaded: load average 22 at rest, 100 at the moment of the timeouts. In dev, Payload spawned `payload generate:types` (a whole extra Node process that loads the full config) every time it started and on every hot reload, and Next starts Payload afresh in each of its page workers. `typescript.autoGenerate: false` in `payload.config.ts` stops it, and types are still generated on purpose with `pnpm generate:types`. Three back-to-back full runs: 15 / 1 / 1 failures in 8.8 / 5.3 / 4.7 min before, 0 / 0 / 1 in 3.9 / 4.2 / 4.7 min after.
